# Personal Portfolio

A personal portfolio website built with **React** and **Vite** to introduce myself, highlight my technical skills, showcase projects, and provide contact information.

## Live Website

**[View Portfolio](https://pwnportfolio.netlify.app/)**

## Features

- Hero section with an introduction
- About section
- Technical skills showcase
- Projects section
- Contact section
- Navigation bar and smooth scrolling
- Dark-themed interface

## Tech Stack

- **Frontend:** React, JavaScript, CSS
- **Build Tool:** Vite
- **Icons:** React Icons
- **Code Quality:** ESLint
- **Deployment:** Netlify

## Getting Started

### Prerequisites

Install Node.js and npm.

### Run Locally

```bash
git clone https://github.com/pwnFirstGit/portfolio.git
cd portfolio
npm install
npm run dev
```

Open the local URL printed in your terminal.

## Available Commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Build the production version |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
